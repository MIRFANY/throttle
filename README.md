
🏃‍♂️ THrottle: The Macro-Runner
GymRat Dash is a lightweight, React-based side-scroller game. Built as a learning project for React hooks, it challenges players to keep their "Gym Rat" (💪) on track by jumping over junk food (🍕) to accumulate protein points.

🚀 Features
State-Driven Physics: Uses useState to handle jumping and game status.

Collision Detection: Real-time hitbox monitoring using getBoundingClientRect.

Responsive Animations: CSS3 Keyframes for smooth obstacle movement.

High-Intensity Gameplay: Fast-paced logic built around the "Gym Rat" lifestyle.

📁 Project Structure


src/
├── App.jsx          # Parent component / Layout
├── GymRun.jsx       # Core Game Engine (Logic & Refs)
├── GymRun.css       # Animations & Visuals
└── main.jsx         # Entry point
🛠️ Installation & Setup
Clone the repository:

Bash

git clone https://github.com/your-username/gymrat-dash.git
Navigate to the folder:

Bash

cd gymrat-dash
Install dependencies:

Bash

npm install
Run the development server:

Bash

npm run dev
